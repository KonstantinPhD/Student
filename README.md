## 🚀 Быстрый старт и запуск

1. **Клонируйте репозиторий на локальную машину:**
   ```bash
   git clone https://github.com
   cd Student
   ```

2. **Настройте виртуальное окружение и установите базовые зависимости:**
   ```bash
   # Для Windows:
   python -m venv venv
   venv\Scripts\activate

   # Для macOS/Linux:
   python3 -m venv venv
   source venv/bin/activate

   # Установка необходимых пакетов
   pip install notebook pandas numpy matplotlib seaborn scikit-learn statsmodels
   ```

3. **Запустите Jupyter среду:**
   ```bash
   jupyter notebook
   # или
   jupyter lab
   ```
   *После этого откроется вкладка браузера, где вы сможете выбрать и запустить любой `.ipynb` ноутбук.*


# 🛠 Шпаргалка по Git: от сохранения до синхронизации

Здесь собраны основные команды Git для локальной работы на ПК и синхронизации с облаком (GitHub/GitLab).

---

## 💻 1. Локальный рабочий цикл (Работа на ПК)

В Git всегда действует правило «трёх шагов» для сохранения кода: **Проверить ➡️ Подготовить ➡️ Зафиксировать**.

*   `git status`  
    **Главная справочная команда.** Показывает текущее состояние репозитория: измененные, новые (untracked) и подготовленные к коммиту файлы.
*   `git add .`  
    **Шаг 1: Подготовка к сохранению.** Собирает все изменения в текущей папке и подпапках в виртуальную «коробку». Без пробела и точки в конце (`.`) команда не сработает.
*   `git commit -m "название коммита"`  
    **Шаг 2: Сохранение на локальный ПК.** Окончательно «запечатывает коробку» и надежно сохраняет снимок (коммит) в историю на вашем жестком диске.

---

## ☁️ 2. Синхронизация с облаком (GitHub / GitLab)

Команды направления движения файлов. Помните: `push` — от себя, `pull` — к себе.

*   `git push origin master`  
    **Сохранить в облако (Выключаем ПК).** Отправляет (толкает) ваши локальные зафиксированные коммиты на сервер `origin` в ветку `master`.
*   `git pull origin master`  
    **Скачать из облака (Включаем ПК).** Забирает (тянет) все новые изменения с сервера на ваш компьютер и автоматически объединяет их с вашими файлами.

---

## 📊 3. Просмотр истории

*   `git log`  
    Выводит полный журнал всех коммитов в репозитории (автор, дата, комментарий).
*   `git log --oneline`  
    Показывает историю коммитов в виде красивого и компактного однострочного списка.

---

## 🔧 4. Полезные настройки (Выполняются один раз)

*   `git config --global core.quotepath false`  
    Отключает кодирование кириллицы. После этого Git начинает нормально отображать русские буквы в названиях файлов (вместо кракозябр вида `\320\224...`).

---

## 🔄 Идеальный рабочий день с Git:
1. **Включили ПК:** `git pull origin master` *(скачали свежее из облака)*
2. **Поработали в Jupyter / написали код.**
3. **Проверили статус:** `git status` *(увидели изменения)*
4. **Подготовили:** `git add .`
5. **Сохранили на ПК:** `git commit -m "Решил домашку №2"`
6. **Перед выключением ПК:** `git push origin master` *(отправили в облако)*
